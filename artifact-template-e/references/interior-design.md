# 灵活内页设计

## 风格固定在何处

固定封面、内容大标题、调色板、画布与品牌背景。标题位置与正文区域按构图确定；保持标题和左上标识可见，不强制旧稿的固定顶部标题区。内容区内的对象尺寸与布局可以重设，源形状坐标不构成约束。

主色使用新模板的 #7928D5、#570BDF、#3C007F，辅以 #5F4FD9、#9A7AF6；浅色用 #E1DAFE、#BCADFD；正文用 #14275C、#141C33、#59637D。可以调整这些颜色的面积与透明度，重点区不必放在页面底部。白色空间、细线和少量紫色重点足以形成同一风格。

## 按信息关系选择结构

| 要表达的内容 | 可以采用的构图 | 需要避免的处理 |
|---|---|---|
| 一个核心结论 | 大字号核心句＋侧边依据或局部示意 | 拆成三个没有必要的卡片 |
| 条件、层级 | 阶梯、分层图、主次清楚的纵向列表 | 对本无先后关系的条件强加箭头 |
| 顺序或操作 | 横向流程、纵向泳道、环节与证据对应 | 每个步骤变成一整段说明 |
| 双方或前后对照 | 双栏、差异矩阵、逐项对应行 | 两栏各自堆砌，无法横向比较 |
| 材料、产品或案例 | 左图右文、上图下解读、文件局部放大注释 | 沿用无关截图或让图片只是装饰 |
| 关系或证据链 | 中心对象＋关联节点、线索汇集图 | 把“相关”画成未经证实的因果 |
| 时间变化 | 时间轴、里程碑＋说明 | 为适配五节点原型编造日期 |
| 真实数量关系 | 原生条形、折线、构成图＋结论 | 无数据时制造图表或大数字 |
| 检查与行动 | 清单表、阶段×责任矩阵、编号条目 | 将清单全部包进等宽大卡片 |
| 法条与解释 | 左侧短引文／条号，右侧解释和应用 | 大段法条照搬或把引文当装饰 |

这些是候选而非封闭菜单，可以设计其他合理构图。没有合适图片时可用清晰的文字、表格与必要的可编辑关系图，不强制找图；装饰插画使用源素材或适用的图片工具。流程节点、比较维度、图表系列的数量由内容决定。

## 一整套PPT的节奏

对8–12页的主题稿，通常可以自然形成4–6种不同的信息结构；这只是规划参考，不是硬性配额。优先避免连续三页完全同构，除非连续案例、同类比较或用户要求有意保持一致。

检查布局的主次比例、阅读方向、视觉焦点是否变化；将三张卡片改为四张，或将同一色带换位置，都不足以说明内容表达已改善。也不要为了多样化把简单信息变成复杂图。

以“电子合同法律效力”10页为例，可考虑：封面→三个判断层次的关系图→书面形式的法条解读→可靠签名条件的2×2要素图→合同生效的判断流程→签署流程与留痕泳道→文件与证据的关联示意→法院审查的证据矩阵→适用范围与误区对照→企业阶段检查表。此例仅展示思考方式，不是固定页序或已核验法律内容；实际按主题与证据重新设计。

## 字体、留白与结论

内容标题固定微软雅黑加粗30pt与源渐变，位置、宽度和对齐可随构图调整，其余文字根据内容区选择层级。可从模块标题18–22pt、正文14–18pt、注释10–12pt开始，按真实尺寸和内容调整；这些不是硬性字号门槛。清晰的少字页面可以比原稿使用更大正文。先改结构、精简或合理分行，再处理局部字号，不能缩小统一大标题。

结论可以放在图表旁、侧栏、页内重点句或底部短行；只有适合该页时才使用紫色横带。不要每页自动添加一句重复正文的口号。所有文字、表格、图表和主要关系图保留可编辑性，最终通过逐页渲染和整套总览验收。

## 图片选择与生成

1. 明确图片用途：是展示真实产品／案例证据，还是解释概念、表现业务场景或提供视觉氛围。模板图片不是必选项，选图从当前页内容出发。
2. 选择来源：用户提供的合适素材、适用的模板图、可用的外部素材或AI生成图均可。事实性材料优先真实来源；概念和装饰配图可按需生成。工具支持生图时主动使用适用的生图工具／技能，不必先让用户自己找图；用户明确限制图片来源时遵循其要求。
3. 生图前确定用途、主体、场景、图框宽高比、主体位置和留白。描述与模板协调的紫色／深紫色调、干净背景和光感，而不是仅要求“科技感”。同一套图片保持视觉一致，但不把所有主题都画成无关的紫色球体或建筑。
4. 生成提示词可采用：“为[页面主题]制作[概念插画／场景配图]，表达[具体业务关系]；用于[横向／纵向]图片区，主体位于[位置]，为[文字区域]留白；使用与e签宝模板协调的紫色、深紫和浅色光感，无标题、无水印、无虚构品牌标识。”这是可调整的参考，不强制所有图片同一种画风。
5. 将新图作为独立图片对象嵌入PPT，匹配蒙版、边界和裁切，保持主体比例。若原图被多个页面或背景共用，创建新的图片部件与关系，只替换目标对象，不能全局覆盖媒体文件而误改封面或母版。图片框、尺寸和图文比例可以随内容重排。
6. 渲染检查新图在实际尺寸下的清晰度、裁切、留白、配色和与文字的关系；检查生成图中的错误手部、乱码和虚构标识。必要时重新生成或换图。外部图片来源放入相应备注；生成图可能被误认为实拍、真实客户或产品证据时，明确标注“AI生成示意图”。

草稿美化时，装饰性或不贴题配图可替换；承载事实的截图、证书、图表和案例图片不能仅为统一风格而删除或改造。AI配图不替代可编辑数据图表、需要准确标注的流程图，也不替代整页PPT。没有可用生图能力或合适图片时，用文字、表格和合理留白完成表达，无需硬塞模板图。
