# 制作与草稿美化工作流

## 选择路径

- **按主题新建**：整理受众和核心信息 → 每页内容与信息关系 → 封面与品牌画布 → 原生对象排版 → 内容及视觉核验。
- **美化草稿**：先读取并渲染每一页，建立“源页 → 输出页”映射，记录文字、数字、单位、图表系列、图片、引用、备注 → 用新模板的品牌画布承载原内容 → 根据关系重排 → 对照源稿逐项核验。默认页数和顺序不变，保留事实与必要限定。源稿封面换成模板封面，只迁移文字；业务数据不能从模板借用。草稿无封面且用户要求严格页数时，先确认如何处理，不覆盖第一张实质内容页。
- 用户只需给主题、方向／材料或草稿。布局选择由AI完成，不要求用户提供逐页排版指令。信息不足且会改变结果时才问；普通视觉取舍可自主决定。

## 可编辑内容制作

以新模板母版1、布局2构建内容页。默认复制第2页标题样式并规范为显式30pt、粗体、微软雅黑、原渐变；将其命名为 `ESIGN_TITLE` 便于审查。位置、宽度和对齐随构图调整。图表采用用户数据，保留编辑能力；只有图片型图表时不能假装获得精确底层数值。未指定新图片时优先保留草稿中与主题相关的图，不把模板里的楼宇、人像或示例指标当必用素材。

第13、22页的深色母版不进入输出；若借鉴其结构，用布局2重建内容区。原图层可能存在组坐标、遮罩与动画，删除／移植内容时连同关系检查；不能只改slideLayout引用就声称完全统一了背景。不要导入草稿原母版作为额外母版。

保留原封面及其完整关系链。若制作工具会改写共享部件，最终合并时恢复源封面、layout1、layout2、master1、主题和相关图片等依赖，解决文件名／关系ID冲突并确认各页正确指向。可直接使用原生PowerPoint工具或支持保真导入导出的工具；技能不要求固定某个编辑器。

## Python辅助脚本

Python 3.9+标准库即可运行，不负责渲染。`references/template-config.json` 记录新文件基准；`references/slots.json` 列出35页文字形状ID、源文本、坐标和媒体审查标记。组内坐标是局部坐标，不能当作最终画布坐标。

```bash
python3 scripts/deck.py slots --slide 2
python3 scripts/deck.py build content.json 输出.pptx
python3 scripts/deck.py audit 输出.pptx
```

`build` 是换字／搭框架助手，不是自动排版引擎。输出路径必须不存在。最小规格：

```json
{
  "slides": [
    {"source": 1, "replace": {"3": ["企业合同管理", "解决方案"], "4": "连接业务流程与可信签署", "6": "", "7": ""}},
    {"source": 2, "blank": true, "title": "合同管理的核心需求"}
  ]
}
```

`blank:true` 清空源页内容对象，仅生成品牌背景与标准标题；后续必须补充正文排版。这是为新布局建立干净画布，不可直接作为成品。

如仅复用某个原型，省略 `blank`，读取该源页slots并填写 `title`、`replace`；所有非空文字必须替换或明确列入 `keep`。`keep`表示有依据地保留原文，不能批量保留示例数据绕过检查。普通内容页会统一标题样式；没有独立标准标题的原型会新增标准标题，需要人工删除／重排原有标题以避免视觉重复。第35页仅在用户需要结束页时复用，填写其所有文字字段。

带图片、图表等的原页需要在确认素材适用后设置 `allow_source_assets:true`。它不是事实校验或商业素材授权。第13、22页不能直接原样复用，使用品牌空白框架重建。封面不受这项额外媒体确认限制，因为用户已要求固定复用。

文字替换按原段落首个run样式重建，不保留复杂段内混合字号／颜色。需要保留富文本或数字强调时用编辑工具处理；不可声称脚本已实现无损富文本改写。复制原生图表时如两页需要不同数据，克隆图表与嵌入工作簿部件后再编辑。生成稿去掉原示例备注，新的引用按实际资料添加。

## 验收范围

`audit`检查：尺寸、首封面非文字对象及文字基础样式、封面／背景依赖、一个母版、布局引用、没有页级背景覆盖，以及 `ESIGN_TITLE` 的显式字体、30pt粗体和渐变。它允许标题移动、改变框宽和对齐，不限制内容区几何。合法工具若重命名等价部件，可能出现严格字节／路径审查失败，应检查并恢复或解释真实差异，不能靠跳过检查宣称保真。

脚本不判断背景是否被前景大图遮住、不计算文字溢出、不核验事实，也不自动美化草稿。必须渲染全稿并查看每页和总览：背景／标识可见、标题统一、留白合理、对象不遮挡、图片不失真、表格图表可读、连续页面构图符合信息关系。草稿模式还须核对源内容覆盖，不能遗漏行列、单位、注释与结论。

目标环境缺少微软雅黑时先寻找可用安装或向用户说明，不能静默替换。源稿和用户草稿始终保留，交付新的可编辑PPT；只有实际在PowerPoint中检查过才能声称已验证PowerPoint显示。
