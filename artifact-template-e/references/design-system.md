# 原稿深度分析与设计规范

本分析来自原始18页PPTX的OOXML结构和逐页渲染图。封面、标准大标题及品牌配色是固定规范；下文对原内容页字号、卡片和结论带的描述是参考观察，不限制新内页布局。分析的是版式，不核验商业、法律或认证事实。预览由Artifact Tool渲染，不等同于PowerPoint最终显示；长标题、混排文本及图表可能有渲染差异。

## 1. 画布和层级结构

- 画布：12192000 × 6858000 EMU，即13⅓ × 7.5英寸，33.8667 × 19.05厘米，16:9。96 DPI下为1280 × 720像素。
- 文件中实际存在1个母版及12个布局部件。使用中的布局只有2个：封面为 `slideLayout1.xml`，第2–18页为 `slideLayout2.xml`。二者均归属 `slideMaster1.xml`。
- 内容页背景和左上标识在布局层，**大标题则是各页普通文本框，不是母版标题占位符**。所以“同一个母版”本身不足以保证标题一致，必须复制标题文本框的 `txBody/lstStyle`、显式字号和几何位置。
- 原主题仍是Office默认主题（Calibri、宋体以及默认蓝橙色），视觉样式主要由对象直接格式覆盖。新图表必须显式设色、设字体；不要修改共享主题导致封面继承变化。

## 2. 封面：固定画面与可改文字

视觉：浅蓝灰底，左侧大标题，右侧高光玻璃感合同/签章插画，底部青、紫、粉、黄色柔和光晕。左上是e签宝与eSign.AI联合标识。必须保留源对象，不从描述重绘。

源依赖：布局1包含 `image1.png`、`image2.png`、`hdphoto1.wdp`、`image3.svg`。幻灯片本身还有SVG对象；必须通过关系链整体保留，不能仅提取一张PNG当封面。

| 字段 | 源形状ID | x/y/w/h（英寸，近似） | 固定样式 | 建议容量 |
|---|---:|---|---|---|
| 主标题 | 3 | 0.929 / 1.324 / 8.437 / 2.471 | 微软雅黑52pt粗体，蓝紫渐变，原阴影 | 两行，每行约8–10个汉字，先按真实宽度检查 |
| 副标题 | 4 | 0.929 / 3.832 / 6.491 / 0.972 | 16pt常规，#4D3E72 | 1–2行，约24–32汉字 |
| 嘉宾、时间、地点 | 6 | 0.906 / 5.226 / 5.791 / 0.694 | 16pt，#4D3E72、70%不透明度 | 按源段落组织，避免超长单位名 |
| 指导/主办 | 7 | 0.952 / 6.481 / 6.600 / 0.350 | 9.5pt，#59637D | 一行，缺少时清空 |

主标题渐变原值：5% `#495AF9`、52% `#6336E2`、99% `#04066C`，角度0°。封面标题不是内容页的黑紫渐变，二者不可互换。坐标是文本框，不是文字首个像素。不得调整框、背景、logo、透明度、裁切来迁就过长标题，应先精简标题。

## 3. 内容页共用背景

布局名称“4_空白”。白底上叠加两张浅色纹理，右上紫粉、左下青蓝，形成轻量数字科技感；不是纯白模板。

- `image4.png`：右侧大纹理，50%不透明度，保留原裁切。
- `image5.png`：左下大纹理，40%不透明度，保留原裁切。
- `image3.svg`：左上联合标识，约 x=0.275、y=0.210、w=2.609、h=0.290英寸。
- 内容区通常左右边距0.62英寸（约59.5px），常规上沿约1.90英寸，下沿6.50–6.90英寸。保留左上标识区域。

## 4. 字体与标题

主字体为**微软雅黑（Microsoft YaHei）**，常规与加粗搭配。正文不是苹方；原第2页存在局部 `PingFang SC Bold`，仅属于局部素材/文字，不推广到新模板。某些符号指定Noto Sans SC，这不是大标题主字体。

标准内容页标题原型：第4页 shape 10。

| 属性 | 精确值 |
|---|---|
| 文本框位置EMU | x=1346158, y=672116 |
| 文本框尺寸EMU | w=9499052, h=752444 |
| 英寸位置尺寸 | 1.4722 / 0.7350 / 10.3883 / 0.8229 |
| 字体 | latin、ea、cs均为微软雅黑 |
| 字号/字重 | 显式run字号30pt，继承粗体；lstStyle中的26pt不是最终字号 |
| 对齐 | 居中，顶对齐，100%行距 |
| 内边距 | 左右约0.10in，上下约0.05in |
| 渐变 | 22%处tx1（黑色）加15%亮度偏移，100%处#570BDF，横向0° |

读取style时要合并run → paragraph → lstStyle → layout/master/theme继承。仅统计 `a:rPr/a:latin` 会漏判统一标题。原第11、12、14页因长标题扩大了文本框，第13页预览出现两行；新生成页采用标准框，并精简标题到约18–24个汉字（中英混排按实际宽度判断）。

原稿内容页常用字号：模块标题14–18pt、总结标题20pt、正文10–13pt、标签10–12pt、核心数字26–40pt。这些是历史尺寸，不是新稿约束。新内容区可以重排并放大正文，具体见 [灵活内页设计](interior-design.md)；仅标准大标题固定30pt。

## 5. 颜色体系

| 用途 | 色值 | 应用 |
|---|---|---|
| 主标题紫 | #570BDF | 标题渐变终点 |
| 浅端紫 | #9A7AF6 | 重点区渐变起点、时间轴、小标记 |
| 深端紫 | #5F4FD9 | 重点区渐变终点 |
| 浅紫填充 | #E1DAFE | 卡片底，保留源透明度 |
| 紫色边框 | #BCADFD | 轻量轮廓和竖线 |
| 深蓝 | #14275C | 模块标题和深色数据 |
| 墨蓝 | #141C33 | 部分正文/结论 |
| 灰蓝 | #59637D | 正文、说明 |
| 极浅灰蓝 | #F8FAFD | 某些内容块底 |
| 浅蓝线 | #D5E0F2、#C9D6EC | 分隔线与卡片轮廓 |
| 白 | #FFFFFF | 深紫面板上的文字 |
| 封面辅助字 | #4D3E72 | 封面和结束页 |

正文重点区常为左浅右深的 `#9A7AF6 → #5F4FD9` 渐变。卡片使用直角或极小圆角、细描边、部分浅阴影。复用原对象的透明度和阴影，不将浅紫色直接设成100%不透明。

原第2页红色强调、第3页红色指标以及第三方图表色是历史页面的局部例外。新内容使用紫色体系；第三方logo和证书原图保留原色。图表可用 #570BDF、#5F4FD9、#9A7AF6、#BCADFD 搭配灰色，其含义和标签优先于装饰。

## 6. 版式语言

原稿以白底、浅色纹理、紫色强调、深蓝文字建立品牌视觉。卡片、底部结论带和案例侧栏是可借鉴组件；新稿可以使用流程、矩阵、图文、原生图表和关系图，保留颜色与标题即可延续风格。内容区的列数、比例、对象位置、形状和留白由内容决定，不要求紫色面积逐页贴近原型。

原案例页左侧约32%与右侧三列的结构适合部分案例，但不是所有案例的固定模板。信息不足时减少模块；证据丰富时可用图片或数据作主视觉。共用布局2只共享背景与标识，不要求相同构图。

## 7. 内容与可用性边界

- 源PPT约80MB，主要由第6页约58MB视频和多张高分辨率背景构成。完整源稿保留在skill，不删原媒体。新PPT未选视频页时脚本可删除输出中的不可达媒体，源稿不变。
- 第3页有原生图表，需要同时更新图表缓存及嵌入工作簿，不能只改旁边文字。
- 原文中的“200%成本下降”、某些时间/认证/客户数据应被视为待核实材料。模板资产的保留不等于允许把它们当新事实。
- 本机PowerPoint资源中发现微软雅黑常规/粗体文件，但不将商业字体复制到分发包。字体在其他机器/渲染器的可用性需分别检查。
