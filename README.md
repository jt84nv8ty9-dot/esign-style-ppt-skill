# e签宝风格ppt

根据主题或资料生成沿用原稿风格的可编辑PPT：固定封面只改文字，统一微软雅黑大标题、紫色配色与内容页母版。

## 下载与安装

从 [Releases](../../releases) 下载完整 Skill 压缩包。完整包包含原始18页PPT（含视频）、全部预览、设计规范、布局目录和Python脚本。请下载发布附件，不要使用仅含仓库说明的 Source code 压缩包。

解压后将整个 `artifact-template-e` 文件夹放入：

- macOS：`~/.codex/skills/`
- Windows：`%USERPROFILE%\.codex\skills\`

## 使用

在支持技能和本地PPT操作的AI工具中加载完整技能文件夹，然后输入：

> 用e签宝风格ppt，制作一份关于“AI如何提升合同管理效率”的10页PPT。

也可以明确调用：

> $artifact-template-e 根据我的主题制作10页PPT，保留封面画面、统一标题字体、配色和母版。

显示名称为“e签宝风格ppt”；兼容调用标识为 `artifact-template-e`。

## 固定设计规范

- 封面插画、背景、标识和位置保持原样，只替换指定文字。
- 普通内容页大标题为微软雅黑加粗30pt、深灰到紫色渐变。
- 内容页共用原稿“4_空白”版式和同一父母版。
- 按内容使用案例、指标、对比、时间轴等布局。
- 生成后检查文字溢出、字体和资产完整性；目标电脑需有微软雅黑。

脚本仅依赖Python 3.9+标准库。图表/视频编辑与逐页渲染需相应PPT工具；只粘贴SKILL.md文字不能准确复用封面和母版。
